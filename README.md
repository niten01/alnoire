# alnoire

## Prerequisites
* [Node JS](https://nodejs.org/en/download)

## Installing

1. clone to `...\steamapps\common\dota 2 beta\addons` (so final path is `...\steamapps\common\dota 2 beta\addons\alnoire`)
2. setup links via [d2am](https://github.com/chrisinajar/dota2-addon-manager)
```sh
cd <DOTA_PATH> # where DOTA_PATH is path to 'dota 2 beta' dir
npm install -g dota2-addon-manager
d2am link
d2am list
```
3. alnoire should be available in dota tools
